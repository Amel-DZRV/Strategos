## Batch 1 notes (M0.4: S1, S2, S9, S4, S5, S17)

- Run on 2026-10-11, claude 2.1.292, Windows 10, sandbox `C:\dev\strategos-sandbox`, default permission mode only. `~/.claude/settings.json` sha256 before and after: `395251894b195ee1979471360b82fe92c86905430bfd3e5b5e8bab04780c360d` (unchanged; top-level listing of `~/.claude` also unchanged). Raw captures: `spike/out/run1/` (hooks, statusline, hooklog.log, tap-timing.log) and `spike/out/hooks` (run 2); both git-ignored.
- **Surprise: sessions start in "auto mode"** (`auto mode on` in the footer) on this account, with or without our injected settings, and after removing the leaked `CLAUDE_PREVIEW_CLASSIFIER_FLOOR`. Auto mode raises no permission dialogs. I cycled to `manual mode` with Shift+Tab (order: auto, manual, accept edits, plan). Strategos must pass the permission mode explicitly (for example `--permission-mode default`) or the Approve flow never sees requests; that flag is untested here.
- The first start showed a workspace trust dialog (cursor starts on "No, exit"); a later start showed a one-off "Claude in Chrome extension detected" prompt (Esc keeps browser tools off). SessionStart over http was missing even in sessions with no dialog.
- `/clear` kept the same hook URL: SessionEnd for the old id, then later events carried the new `session_id` (8a950f16...). Early S11 evidence; the SessionStart for the new id did not arrive over http.
- `SubagentStop` (empty `agent_type`, with an `agent_id`) fires after almost every turn even with no Task tool: internal helper agents. Do not show it as a user-visible subagent.
- Hooks are POSTed by axios (`user-agent: axios/1.15.2`), keep-alive; non-held events were answered 200 empty.
- Spike script changes: `hooklog.ts` gained `note <text>` (PostToolUse returns additionalContext); `tap.mjs` writes start/end/ms/process lifetime/shell to `out/tap-timing.log`; `hostpty.ts` also scrubs `CLAUDE_PID`, `CLAUDE_EFFORT`, `CLAUDE_PREVIEW_*`, has `--ss-command`, and writes the run token to `out/token-<id>.txt` (git-ignored) for the equality check; `mksettings.ts` has `sessionStartCommand`; new `relay.mjs` (command-hook relay) and `make-fixtures.ts` (redaction: home path in all spellings and the 8.3 temp path to `~`, token to `<redacted>`, strings over 2 KB cut, non-hook attachments and the user email dropped from transcripts).
- hooklog `allow`/`deny` acts on the OLDEST held request: a stale request that the TUI already answered swallows the command. The daemon must drop held requests once PostToolUse/Stop shows the tool already ran.
