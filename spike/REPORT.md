Raw captures: `spike/out/hooklog-batch2.log`, `spike/out/hooks`, `spike/out/statusline`, `spike/out/txwatch.log` (git-ignored).
- **Design-relevant surprises**
  1. **Esc at a permission dialog closes our held PermissionRequest connection; answering Yes in the TUI does not** (batch 1). A daemon can treat `res close` as "answered or cancelled in the terminal", but only for cancel. It still has to drop held requests on PostToolUse/Stop.
  2. **Interrupts leave no hook trace.** The only signals are the transcript marker (`[Request interrupted by user]` or `... for tool use]`, within about 0.3 s), `sessions/<pid>.json` going to `idle`, and the held connection closing at a dialog. Esc before the first token leaves no marker (the prompt returns to the input box).
  3. **Agent View is a real escape hatch.** Without `disableAgentView`, one ArrowLeft starts a hidden `claude daemon` and moves the conversation to a background process under a new session id, while our pty keeps a thin client. Keep the flag always, and treat an unexpected new session id + `parkedJobId` in `sessions/<pid>.json` as "moved to background" (recovery: `claude stop <id>`, `claude rm <id>`).
  4. **Cost on identity change differs by kind**: /clear and /branch start from 0; /resume restores the old total; /compact keeps it. Store cost per Claude session id (plan C3) and add them, but do not add a resumed id twice.
  5. **/compact fires SessionStart** (source `compact`, same id) through the relay; /branch's SessionEnd says `reason:"resume"` and its SessionStart has no parent id.
  6. **SessionStart must stay a command-hook relay** (batch 1).
  7. **Agent tool calls are asynchronous by default** (placeholder `tool_result`, later `<task-notification>`), and `SubagentStart` does fire for them; the earlier absence in batch 1 was only because no subagent was requested.
  8. Worktrees of a trusted repo inherit trust (no dialog), inside or outside the repo.
  9. `sessions/<pid>.json` reports `waiting` with `waitingFor:"permission prompt"` during a held request, so the reconciler can show a "probably needs you" state even with the hook server down.
  10. In a TUI the model's text streams on screen but the transcript gets one record per completed block, so the chat view lags the TUI for long text.
- Mistakes worth remembering when scripting: Git Bash rewrites a leading `/word` argument into `C:/Program Files/Git/word` (use `MSYS_NO_PATHCONV=1` when sending slash commands), and a bare `cat > /dev/null` blocks on stdin.
- Spike script changes: `hostpty.ts` gained `--perm`, `--extra`, `--settings-file`; new `drive.mjs` (headless control), `tx.mjs` (transcript tail summary), `txwatch.mjs` (10 ms transcript poller for S6 timing), `s8.ts` (Option E probe), `make-fixtures2.ts` (batch 2 fixtures, same redaction), `update-report.mjs` (this report's rows).
